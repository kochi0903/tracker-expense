# Expense Tracker

A modern expense tracking application to help you manage your personal finances effectively.

## Features

- Track income and expenses
- Categorize transactions
- View spending analytics
- Monthly/yearly reports
- Responsive design
- Data persistence

## Tech Stack

- Frontend: React.js
- Styling: CSS/SCSS
- State Management: React Context API
- Data Storage: Local Storage

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/kochi0903/tracker-expense.git
```

2. Install dependencies
```bash
cd tracker-expense
npm install
```

3. Start the development server
```bash
npm start
```

## Usage

1. Add new transactions using the "Add Transaction" button
2. View your balance and transaction history
3. Filter transactions by category or date
4. Generate reports for specific time periods
